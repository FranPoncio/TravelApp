# Reglas de datos y frontend

- Mantener la interfaz bilingüe ES/EN cuando se agregue contenido.
- Cada punto turístico necesita identificador, nombre, categoría, coordenadas, imagen y sinopsis.
- Verificar coordenadas y fallback de imágenes antes de publicar.
- Mantener accesibles los controles del mapa y los pines.
- No presentar precios ni transporte orientativo como información oficial.
- Si se cambia el esquema de datos, actualizar el pipeline o el código consumidor en la misma tarea.
